# PlantPulse 🌱

PlantPulse is an Android MVP for a plant health assistant.

## Current MVP
- Home dashboard
- Plant profiles
- Plant Doctor questionnaire
- Transparent rule-based health guidance
- Light/watering guidance
- Material 3 UI

## Next build stage
Connect:
1. Android photo picker/camera
2. On-device or backend image analysis
3. Plant species identification
4. AI symptom analysis
5. Local weather-aware care
6. Plant history and reminders
7. Image-to-image health comparison

Important: photo-based plant diagnosis should be presented as probabilistic guidance, not a guaranteed laboratory diagnosis.

## Build
Open the project in Android Studio and let Gradle sync. Then run on an Android device/emulator.
